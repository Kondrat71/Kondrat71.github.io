Privacy Policy

Last updated: 10 October 2026

Story Reels Poster ("the App") is a personal automation tool used only by its developer for his own TikTok account.

Data we access

Through TikTok Login Kit the App receives an access token and a refresh token for the owner's own account and basic profile information (display name) to confirm which account is connected. Through the Content Posting API it uploads videos to that account.

How data is used and stored

Tokens are stored as encrypted secrets in the owner's private GitHub repository and are used only to publish the owner's videos. No data is sold, shared with third parties, or used for advertising. The App does not collect data about other TikTok users or visitors of this website.

Deletion

The owner can revoke access at any time in TikTok settings and delete the stored tokens from the repository secrets.
